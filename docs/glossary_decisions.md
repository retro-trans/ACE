# Glossary decisions

Main source for names: akurasu.net (Another Century's Episode pages, mirrored in `work/glossary/akurasu/` by
`tools/akurasu_terms.py`). The SRW MX project's akurasu-derived glossary is used for shared series terms.
Machine-readable copy: `work/glossary/decisions.json`. Locked spellings: `work/glossary/glossary.json`.

| Term | English | Reason |
| --- | --- | --- |
| アモンデュール・スタック | Amon Duule "Stack" | akurasu's heading pairs this name with アシュラテンプル (wiki copy error). |
| ＵＣＥ（地球統一機構） | UCE (United Community of Earth) | No akurasu entry; SRW Wiki and pixiv. Title kept to "UCE" for the 27-byte title budget. |
| 統一帝国ギガノス | Unified Empire of Giganos | No akurasu ACE entry. SRW MX's "United Lunar Empire Giganos" adds a word not in the Japanese. |
| ν Gundam | ν Gundam | akurasu spelling; the game font has the ν glyph. |
| 宇都宮比瑪 | Hime Utsunomiya | akurasu (Alpha 2) writes "Utsumiya", a misreading of 宇都宮. |
| ショウ・ザマ | Show Zama | akurasu spelling kept; the official dub uses "Sho". |
| 量産型ゲシュペンストＭｋ-Ⅱ | MP Gespenst Mk-II (title) | Full akurasu name "Mass Production Gespenst Mk-II" exceeds the title budget; full name in the description. |
| クラウドブレイカー量産型 | Cloudbreaker MP Type (title) | Same reason; full name in the description. |
| ル・カイン | Le Cain | akurasu SRW J Character List; "Ru Kain" appears only in episode-title translations. |
| ジョナサン・グレーン | Jonathan Green | akurasu SRW Alpha 2 Character List; replaces "Glenn" from the first encyclopedia pass. |
| ギガノスの蒼き鷹 | Blue Hawk of Giganos | Literal (鷹 = hawk) and matches SRW MX; akurasu episode titles say "Blue Eagle". |
| ゲア・ガリング | Gea Garing | akurasu episode list writes "Gea Gring", dropping a syllable. |
| ジャミトフ・ハイマン | Jamitov Hymem | Official English; akurasu "Hymen" reads as an unintended English word. |
| Mission names (5) | Suppress Enemy Raiders, Quell Enemy Remnants, Beat Enemy Strike Force, Subdue Giganos Empire, Defeat Unknown Craft | The mission-name field holds 200 units / 27 bytes; the akurasu names do not fit (two are also misspelled there). |
| 統一地球暦 | Unified Earth Calendar | Calendar era in the opening and ending movies; no akurasu or official English, so a literal rendering. |
| 地球統一機構 (movie) | Earth Unification Organization | Only in the opening movie, in brackets under its own English "UCE -United Community of the Earth-"; literal, so the line does not repeat. |
| Staff names (movie credits) | Hepburn romanization | Known English spellings where sourced (Wikipedia, voice cast). Other readings are unverified and noted in the movie spec. |
